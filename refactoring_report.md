# Отчёт по рефакторингу конвейера прогнозирования оттока

Конвейер перенесён из учебных ноутбуков в запускаемые Python-модули. Он самостоятельно собирает признаки из архива TDG, сравнивает две модели и сохраняет выбранную модель вместе с метриками и отчётом о качестве данных. Для контрольного прогона использован исходный `out.zip` варианта S с seed 20260827.

## Функции и границы этапов

| Функция | Назначение |
| --- | --- |
| `load_data` в `churn_data.py` | Читает суточные файлы CDR из архива, проверяет даты, удаляет дубликаты, агрегирует события по абонентам и присоединяет метку оттока. Возвращает таблицу признаков и статистику загрузки. |
| `preprocess` в `pipeline.py` | Отбирает восемь числовых признаков из явно заданного списка. Делит абонентов с сохранением пропорций классов на обучение, валидацию и тест в долях 60/20/20. |
| `train_model` в `pipeline.py` | Обучает логистическую регрессию и случайный лес отдельными вызовами. Для логистической регрессии масштабирование входит в объект модели и обучается на тренировочной части. |
| `evaluate` в `pipeline.py` | Считает Average Precision, ROC-AUC, Precision, Recall, F1 и матрицу ошибок. Модель выбирается по Average Precision на валидации. Для выбранной модели затем вычисляются тестовые метрики. |
| `save_artifacts` в `pipeline.py` | Сохраняет `features.parquet`, `model.joblib`, `metrics.json` и `data_quality.json` в одном ZIP-архиве. |
| `run_pipeline` в `pipeline.py` | Читает конфигурацию, настраивает логирование и выполняет этапы по порядку. Доступна из командной строки через `python pipeline.py`. |

## Конфигурация и логирование

В `config.json` заданы пути к архиву и результатам, дата прогноза, длина окна наблюдения, длина окна недавней активности и горизонт прогноза. Там же заданы доли выборок, `random_state`, гиперпараметры моделей, порог классификации, уровень и формат логирования. Пути можно переопределить аргументами `--archive` и `--output`. В Docker Compose путь к архиву на хосте задаётся через `DATASET_PATH`.

В журнал выводятся количество принятых записей, размеры выборок, этапы обучения, метрики и путь к результату. Сводка по качеству данных сохраняется в `data_quality.json` внутри архива.

## Решения при рефакторинге

Для подготовки признаков потребовалось согласовать форматы дат и определить, какие сведения доступны на момент прогноза. В `churn_data.py` для дат ISO и формата `день.месяц.год` заданы отдельные правила разбора. Активные дни считаются по уникальным календарным датам событий.

Дата прогноза разделяет период наблюдения и период разметки. В контрольном запуске признаки рассчитаны по событиям с 1 октября по 29 ноября 2025 года, поступившим до начала 30 ноября. Целевая переменная описывает уход в следующие 30 дней. Для каждой модели используется один и тот же список признаков и одно разбиение выборки.

Для локального запуска и Docker используется одна точка входа. Локально архив читается с диска, а в контейнере Docker Compose подключает его к тому же пути, который задан в конфигурации.

## Идемпотентность и результаты проверок

Фиксированный seed задаёт разбиение и обучение моделей. Каждый прогон записывает полный комплект артефактов во временный архив и публикует его через `os.replace` только после успешного завершения записи. Повторный запуск обновляет архив целиком по тому же пути.

| Проверка | Результат |
| --- | --- |
| Автоматический тест подготовки данных | Проверены два формата дат, дубликаты, число активных дней, исключение событий и поступлений за границей прогноза, а также отбор абонентов. |
| Два локальных запуска на одинаковых входах | Совпали контрольные суммы SHA-256 архивов. |
| Полный запуск в Docker на CPU | Контейнер завершился успешно при лимитах 4 CPU и 4 ГиБ памяти. Таблица признаков и отчёт о качестве совпали с локальным прогоном. Загруженная из архива модель воспроизвела тестовые метрики. |
| Docker Compose с `data/out.zip` и с прямым путём | Оба варианта завершились успешно на одном наборе данных и дали побайтно одинаковые архивы. |

В контрольном запуске сформирована выборка из 186 405 абонентов. По результатам валидации выбран случайный лес. Он получил на тестовой выборке **ROC-AUC 0,6562** и **Average Precision 0,1068**.
